## Features

- A high-impact hero ("Stop waiting.") with a free-trial call to action
- **Community gym** story, plus the facilities, trainers, and nutrition store
- **Simple membership pricing**
- **Training plans** matched to different goals
- Member testimonials
- **FAQs**, a contact page, privacy policy, and terms
- A responsive, mobile-first layout

## Tech stack

Hand-written HTML, CSS, and vanilla JavaScript. It has no frameworks and no
build step.

```
index.html, about.html, membership.html, training-plans.html, faqs.html, contact.html
privacy.html, terms.html
style.css, script.js
```

## Run locally

```bash
git clone https://github.com/dean1234533/Muscle-Hut.git
cd Muscle-Hut
open index.html
```
